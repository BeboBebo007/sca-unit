# SCA-Unit Public Examples

This directory contains simple public examples showing how SCA-Unit can compare two structured software or logical states.

## Files
- example_system_v1.json: first sample structural state
- example_system_v2.json: second sample structural state
- example_paid_structural_report.md: generated human-readable report

## Example command
sca-unit examples/example_system_v1.json examples/example_system_v2.json --output examples/example_raw_report.json

## Purpose
These examples help users understand SCA-Unit quickly without exposing protected internal architecture.
