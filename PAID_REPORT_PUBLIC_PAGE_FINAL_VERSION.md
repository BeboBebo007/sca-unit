# SCA-Unit Paid Structural Report Service

## Service overview
SCA-Unit Paid Structural Report is a manual structural compatibility assessment service based on two JSON structural state files provided by the customer.

## What you provide
- First JSON structural state file
- Second JSON structural state file
- Confirmation of which file represents the first state and which file represents the second state

## What you receive
- A paid Markdown structural report
- Raw SCA-Unit assessment JSON only if included in the agreed service scope

## Important safety notice
Do not submit passwords, access tokens, API keys, private keys, credentials, secrets, or unrelated private implementation details.

## Service limitations
This service is not legal, financial, medical, cybersecurity, or compliance certification.

## Manual service boundary
This is a manual service. It does not include automated payment handling, automated ordering, customer portal access, or continuous monitoring.

## Protected architecture boundary
This service uses only the public SCA-Unit workflow. It does not expose AMNE internals or protected structural architecture.

## Before work begins
The service scope, price, input files, and delivery format should be clear before any manual report work starts.
