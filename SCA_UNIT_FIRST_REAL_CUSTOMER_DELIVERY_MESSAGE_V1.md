# SCA-Unit First Real Customer Delivery Message v1.0

## Purpose
Provide a safe delivery message for sending the completed manual SCA-Unit Structural Report to the first real customer.

## Message status
Approved public-safe customer delivery message template.

## Customer delivery message

Hello,

Thank you for using the SCA-Unit Structural Report service.

The structural comparison report has been completed and is attached or included with this message.

This report compares the two JSON structural state files you provided and presents the structural compatibility assessment in a readable format.

Important limitation: this report is not a legal, financial, medical, cybersecurity, or compliance certification. It is a structural comparison report only.

Please review the report and let me know if any part of the wording is unclear or if you need a brief explanation of the reported structural comparison results.

Kind regards,
SCA-Unit

## Internal use note
Use this message only after the report has passed manual review and has been approved for customer delivery.

## Safety rule
Do not attach unsafe files, temporary files, customer secrets, credentials, or internal working files.

## Protected knowledge rule
This message must not mention AMNE internals or protected structural architecture.
