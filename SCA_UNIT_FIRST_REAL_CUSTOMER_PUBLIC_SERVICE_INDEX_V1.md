# SCA-Unit First Real Customer Public Service Index v1.0

## Purpose
Provide a public-safe index for the first controlled real customer Structural Report service materials.

## Index status
Public service index for controlled first customer requests.

## Service overview
SCA-Unit provides a manual Structural Report service for comparing exactly two JSON structural state files.

The service turns a structural comparison into a readable report with a verdict, compatibility score, structural metrics, and practical recommendation.

## Public service files
- SCA_UNIT_FIRST_REAL_CUSTOMER_PUBLIC_SERVICE_READINESS_NOTICE_V1.md
- SCA_UNIT_FIRST_REAL_CUSTOMER_PUBLIC_SERVICE_REQUEST_INSTRUCTIONS_V1.md
- SCA_UNIT_FIRST_REAL_CUSTOMER_PUBLIC_SERVICE_PAGE_UPDATE_V1.md

## Start here
For a first controlled customer request, start with:
- SCA_UNIT_FIRST_REAL_CUSTOMER_PUBLIC_SERVICE_PAGE_UPDATE_V1.md

Then read the request instructions:
- SCA_UNIT_FIRST_REAL_CUSTOMER_PUBLIC_SERVICE_REQUEST_INSTRUCTIONS_V1.md

## Accepted request type
- Exactly two JSON structural state files
- Clear first-state and second-state order
- Structural comparison only

## What not to send
Do not send passwords, API keys, tokens, private keys, credentials, confidential secrets, sensitive personal data, or unrelated private documents.

## Service boundary
SCA-Unit provides a structural comparison report. It is not intended to replace legal, financial, medical, cybersecurity, or compliance advice.

## Protected knowledge rule
This index must not mention AMNE internals or protected structural architecture.
