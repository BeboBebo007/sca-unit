SCA-Unit Demo Checklist



Before the Demo



1\. Confirm the working directory is C:\\SCA-Unit

2\. Activate the development environment

3\. Confirm all tests pass

4\. Confirm the example JSON files exist

5\. Confirm the release candidate report can be generated

6\. Confirm no protected source code is visible

7\. Confirm the demonstration files contain no customer-confidential data



During the Demo



1\. Explain the customer problem

2\. Show the two structural inputs

3\. Run the assessment

4\. Show the generated report

5\. Explain each output field

6\. Clarify the limits of the current prototype

7\. Explain that protected mechanisms remain private

8\. Record customer questions and reactions



After the Demo



1\. Save the generated report

2\. Record the customer feedback

3\. Record requested features

4\. Record possible integrations

5\. Record pricing feedback

6\. Decide whether to propose a pilot

7\. Do not send source code or internal technical files



Demo Approval Rule



A demonstration is approved only when:



1\. The tests pass

2\. The example run succeeds

3\. The report is reproducible

4\. The working tree is clean

5\. The protected distribution policy is respected
