SCA-Unit Customer Demo Script



Demo Objective



Show how SCA-Unit compares two structural descriptions and produces a clear compatibility report.



Demo Duration



Recommended duration: 10 to 15 minutes.



Demo Flow



1\. Introduce the customer problem.

2\. Explain that SCA-Unit compares structures, not only text differences.

3\. Show the first JSON structure.

4\. Show the second JSON structure.

5\. Run the assessment.

6\. Display the generated report.

7\. Explain node similarity.

8\. Explain edge similarity.

9\. Explain overall compatibility.

10\. Explain conflict score.

11\. Explain the final verdict.

12\. Clarify that protected mechanisms remain server-side.

13\. Ask the customer which decision the report could support.



Demo Example



Input files:



examples/structure\_a.json

examples/structure\_b.json



Expected result:



Node similarity: 0.8

Edge similarity: 0.75

Compatibility: 0.775

Conflict: 0.0

Verdict: compatible



Customer Questions



1\. Is the report understandable?

2\. Which field is most useful?

3\. Which field requires explanation?

4\. What kind of structures would you compare?

5\. Would this report support a real decision?

6\. Would you use this as a service?

7\. What integration would you need?

8\. What pricing model would be acceptable?
