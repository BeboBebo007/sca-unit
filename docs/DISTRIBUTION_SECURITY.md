\# SCA-Unit Protected Distribution Policy



\## Current package status



The current Python wheel and source distribution contain readable source code.



They are approved only for:



\- Internal development

\- Controlled testing

\- Private demonstrations

\- Non-proprietary prototype validation



They must not contain protected SCA-Unit or AMNE mechanisms.



\## Prohibited public contents



The following must remain outside publicly distributed packages:



\- Structural Consolidation Operator

\- Proprietary energy formulations

\- Candidate generation mechanisms

\- Optimization and adaptive weighting

\- Self-evolution mechanisms

\- Protected decision mechanisms

\- Unpublished patent material

\- AMNE internal architecture



\## Commercial architecture



The protected engine must execute on a controlled server.



The customer-facing component may contain only:



\- Input validation

\- Request preparation

\- Authentication

\- Result presentation

\- Non-proprietary examples



The customer must not receive the protected engine source code.



\## Publication rule



No package may be uploaded to a public repository without a separate security and intellectual-property review.
