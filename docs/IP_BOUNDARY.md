# SCA-Unit Intellectual Property Boundary

## Public Prototype Scope

This repository may contain:

- Structural input representations.
- Basic compatibility assessment.
- Basic conflict measurement.
- Deterministic public interfaces.
- Tests and demonstration examples.

## Protected Scope

The following components must remain private unless explicitly authorized:

- The Structural Consolidation Operator.
- Proprietary structural energy formulations.
- Optimization and candidate-generation mechanisms.
- Preservation and rejection rules.
- Adaptive weighting mechanisms.
- Self-evolution mechanisms.
- Patent claim implementation details.
- Any mechanism derived from unpublished AMNE research.

## Separation Rule

SCA-Unit and AMNE remain independent projects.

No AMNE law, primitive, algorithm, or unpublished mechanism may be
copied into this repository without an explicit intellectual-property
review and a recorded decision.
