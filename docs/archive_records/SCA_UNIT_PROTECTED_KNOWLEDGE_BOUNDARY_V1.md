# SCA-Unit Protected Knowledge Boundary v1.0

## Purpose
Define what may be public and what must remain protected in the SCA-Unit project.

## Public layer
The public SCA-Unit layer may include the Python package, CLI usage, public examples, README documentation, paid report workflow, customer instructions, validation behavior, and manual service documentation.

## Protected layer
Protected knowledge includes AMNE internals, protected structural architecture, unpublished structural laws, private reasoning methods, sovereign architecture concepts, internal strategic extensions, and any non-public invention material.

## Core rule
Public documentation and code must not expose AMNE internals or protected structural architecture.

## Allowed public content
- Public SCA-Unit package usage
- CLI examples
- JSON input and output examples
- General structural compatibility language
- Manual paid report service description
- Customer safety instructions
- Validation limits
- Public roadmap items approved for disclosure

## Not allowed in public content
- AMNE internals
- Protected structural architecture
- Unpublished invention mechanisms
- Internal mathematical laws not approved for release
- Private strategic roadmap details
- Patent-sensitive implementation logic
- Customer secrets or private submitted data
- Claims that overstate legal, financial, medical, cybersecurity, or compliance value

## Documentation review rule
Every public-facing document must be reviewed against this boundary before release.

## Engineering review rule
Every new public feature must be checked for protected-knowledge exposure before publication.

## Business review rule
Commercial materials must describe the public SCA-Unit service only and must not imply access to protected internal architecture.

## Safe positioning
SCA-Unit may be described as a structural compatibility assessment tool and manual report service.

## Unsafe positioning
SCA-Unit must not be described as exposing or commercializing AMNE internals.

## Escalation rule
If a document, feature, or claim is unclear, it must remain private until explicitly approved for public release.
