# SCA-Unit Branding Decision

SCA-Unit is the public package name for the first non-proprietary structural assessment library.

AMNE is reserved as the broader umbrella architecture and long-term platform vision.

Current decision:
- Publish the first Python package as sca-unit.
- Do not expose the full AMNE architecture in the package name.
- Keep SCA-Unit focused, practical, and developer-friendly.
- Later, SCA-Unit may be described as part of the AMNE roadmap.
