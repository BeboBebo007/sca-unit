# SCA-Unit Official Documentation System v1.0

## Purpose
Define the official documentation system for SCA-Unit after the first public investment-ready release phase.

## Highest reference
SCA-Unit Master Strategy is the highest governing reference for all project documentation.

## Documentation levels
1. Foundation documentation
2. Product documentation
3. Engineering documentation
4. Business documentation
5. Community documentation
6. Investment documentation
7. Operations documentation

## Document classes
Frozen documents change rarely and only by explicit governance decision.

Living documents are updated when new product, market, customer, or technical evidence appears.

## Operating principles
- Market evidence guides product decisions
- Product decisions guide engineering work
- Engineering work serves real use cases
- Decisions are based on evidence, not assumptions
- Quality is measured by user impact, not feature count
- Public documentation must not expose AMNE internals or protected structural architecture
