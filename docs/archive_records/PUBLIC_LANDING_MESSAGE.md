# SCA-Unit Public Landing Message

## One-line message
SCA-Unit compares two structured JSON states and produces a deterministic structural compatibility assessment.

## Public positioning
SCA-Unit is a Python toolkit for developers, reviewers, and technical teams who need to understand structural differences between two software or logical states before migration, integration, or system evolution.

## What it does
- Compares two structured JSON representations
- Measures node similarity and edge similarity
- Reports structural compatibility
- Detects shared-domain conflict
- Produces a clear structural verdict
- Supports generated human-readable reports

## What it is not
- Not a private AMNE release
- Not a protected architecture disclosure
- Not a general AI model
- Not an outreach campaign

## Install
pip install sca-unit==0.4.0

## Quick command
sca-unit first.json second.json

## Public principle
Public visibility only. No outreach. No cold messages.
