# SCA-Unit

SCA-Unit is a structural compatibility assessment prototype.

It compares two JSON-based system representations as structures, not as isolated values.

## What it does

- Detects structural drift between two JSON documents
- Produces a deterministic structural assessment report
- Shows compatibility, similarity, conflict, verdict, and drift summary
- Provides a local browser demo
- Exports reports as JSON or HTML
