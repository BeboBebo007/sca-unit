# SCA-Unit Product Constitution v1.0

## Purpose
Define the governing constitution for SCA-Unit as a public technical product and controlled manual paid service.

## Product identity
SCA-Unit is a structural compatibility assessment tool for comparing two structural state representations and producing explainable compatibility outputs.

## Governing principle
SCA-Unit must remain useful, understandable, testable, and safe as a public product.

## Product mission
Provide developers, researchers, and technical users with a practical way to compare structural state files and generate readable structural reports.

## Public product boundary
The public product includes the SCA-Unit Python package, CLI workflow, documented report generation flow, public examples, and manual paid Structural Report service.

## Protected knowledge boundary
The public product must not expose AMNE internals or protected structural architecture.

## Decision principles
- Market evidence guides product decisions
- Product decisions guide engineering work
- Engineering work serves real use cases
- Features must support a clear user need
- Documentation must remain clear and maintainable
- Claims must remain accurate and limited
- Public materials must not overstate capabilities

## Current commercial model
SCA-Unit supports a public free package and a controlled manual paid Structural Report service.

## Current service boundary
- Manual service only
- No automated payment handling
- No automated ordering system
- No customer portal
- No continuous monitoring service
- No legal, financial, medical, cybersecurity, or compliance certification

## Success indicators
- Clean public repository
- Usable package installation
- Clear README and public documentation
- Validated customer input workflow
- Repeatable paid report generation
- First controlled real customer run
- Evidence-based product improvements

## Governance rule
Frozen documents may change only by explicit governance decision. Living documents may change when supported by new product, market, customer, or technical evidence.
