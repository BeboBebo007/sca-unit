## Product direction
SCA-Unit can support a public Structural Compatibility Report service based on two customer-provided JSON structural states.

## Customer-facing path
A visitor can start from README, open the paid-report package index, understand the service, review pricing, follow order instructions, and inspect the sample report.

## Business boundary
This is an early public validation layer, not an automated payment system and not an external-investor plan.

## Safety boundary
No AMNE internals or protected structural architecture exposed.

## Publishing principle
Public visibility only. No outreach. No cold messages.
