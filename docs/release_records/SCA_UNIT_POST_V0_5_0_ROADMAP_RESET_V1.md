# SCA-Unit Post-v0.5.0 Roadmap Reset v1.0

## Purpose
Reset the roadmap after the public release of SCA-Unit v0.5.0.

## Roadmap status
Post-release roadmap reset.

## Current public release
v0.5.0

## Current public package
sca-unit==0.5.0

## Current release theme
Typed Relation Public API.

## Completed foundation
SCA-Unit now has:
- public PyPI package
- versioned release history
- GitHub release tag
- documented public API
- typed relation conflict detection
- typed relation conflict counting
- typed relation validation helper
- public installation verification
- stable legacy public API

## Strategic meaning
v0.5.0 establishes SCA-Unit as a small but real public structural assessment package with typed relation capability.

## Available next directions
The next roadmap can move in one of four directions:

### Option 1: CLI integration
Add command-line access for typed relation conflict checks.

### Option 2: Report integration
Include typed relation findings in structured assessment reports.

### Option 3: SCA-Audit Lite preparation
Prepare a small project-level audit workflow based on JSON inputs and typed relations.

### Option 4: Public trust layer
Improve README, examples, documentation, and public credibility before adding more functionality.

## Recommended next direction
The recommended next direction is report integration before SCA-Audit Lite.

## Why report integration first
Report integration turns the typed relation engine into something easier to understand, demonstrate, and eventually sell as a paid report.

## Not recommended immediately
- SaaS
- enterprise platform
- automatic repository scanning
- company-wide data processing
- complex web dashboard

## Commercial path
The near-term commercial path remains:
free Python package plus paid manual structural reports.

## Safe public positioning
SCA-Unit should continue to be described as a structural assessment package, not as a full company audit platform.

## Suggested next milestone
Typed Relation Report Integration Plan v1.

## Final roadmap result
After v0.5.0, the best next move is to connect typed relation findings to human-readable report output.
