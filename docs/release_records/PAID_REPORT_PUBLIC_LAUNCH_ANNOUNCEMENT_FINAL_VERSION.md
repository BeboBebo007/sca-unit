# SCA-Unit Paid Report Public Launch Announcement Final Version

## Public announcement
SCA-Unit now offers a manual paid Structural Report service.

The service provides a structural compatibility assessment based on two customer-provided JSON structural state files.

Customers receive a readable Markdown structural report. Raw SCA-Unit assessment JSON may also be provided if included in the agreed service scope.

## Use cases
- Compare two structural state files
- Review structural similarity and difference
- Produce a readable structural compatibility report
- Support manual structural assessment work

## Customer safety notice
Customers must not submit passwords, access tokens, API keys, private keys, credentials, secrets, or unrelated private implementation details.

## Service boundaries
This is a manual service only. It does not include automated payment handling, automated ordering, customer portal access, or continuous monitoring.

## Limitation
This service is not legal, financial, medical, cybersecurity, or compliance certification.

## Protected architecture boundary
The service uses only the public SCA-Unit workflow. It does not expose AMNE internals or protected structural architecture.
