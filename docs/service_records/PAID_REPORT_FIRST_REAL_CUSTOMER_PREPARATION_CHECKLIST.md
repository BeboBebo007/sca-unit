# SCA-Unit Paid Report First Real Customer Preparation Checklist

## Purpose
Define the preparation checklist before accepting the first real customer for the manual paid SCA-Unit structural report service.

## Before accepting the customer
- Confirm that the service scope is clear
- Confirm that pricing is clear before work begins
- Confirm that the service is manual and not automated
- Confirm that the customer understands this is a structural compatibility assessment only
- Confirm that the customer understands this is not legal, financial, medical, cybersecurity, or compliance certification

## Customer input requirements
- Customer must provide two JSON structural state files
- Customer must confirm which file is the first state
- Customer must confirm which file is the second state
- Customer must not send passwords, tokens, API keys, private keys, credentials, or secrets
- Customer must not send unrelated private implementation details

## Internal preparation
- Prepare a temporary working folder
- Prepare the paid report generation command
- Prepare the delivery email template
- Prepare the rejection email template
- Prepare the correction email template
- Prepare the service run record template

## Delivery preparation
- Deliver only the paid Markdown report unless raw JSON is included in scope
- Do not deliver temporary files
- Do not deliver internal notes
- Do not expose AMNE internals or protected structural architecture

## Safety boundary
No AMNE internals or protected structural architecture exposed.
