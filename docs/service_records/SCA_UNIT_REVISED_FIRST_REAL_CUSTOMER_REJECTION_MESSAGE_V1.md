# SCA-Unit Revised First Real Customer Rejection Message v1.0

## Purpose
Provide the revised positive-language rejection message for the first real customer request when the submitted request does not match the current SCA-Unit Structural Report workflow.

## Message status
Approved public-safe positive customer rejection message template.

## Customer rejection message

Hello,

Thank you for your interest in the SCA-Unit Structural Report service.

SCA-Unit is designed to turn two JSON structural state files into a clear, readable structural comparison report.

After reviewing the request, it does not currently match this focused workflow, so I cannot prepare a useful structural comparison report from the submitted material.

The service works best when the request includes exactly two JSON structural state files and a short note confirming which file represents the first state and which file represents the second state.

No report will be generated from the current submission.

You are welcome to submit a new request later if it is limited to two JSON structural state files for structural comparison.

This report is a structural comparison report. It is not intended to replace legal, financial, medical, cybersecurity, or compliance advice.

Kind regards,
SCA-Unit
