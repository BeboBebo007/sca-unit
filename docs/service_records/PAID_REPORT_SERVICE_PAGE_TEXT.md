# SCA-Unit Paid Report Service Page Text

## Service title
Structural Compatibility Report

## Short description
Compare two structured JSON states and receive a clear structural compatibility report with a verdict, score, risk interpretation, and practical recommendation.

## Who this is for
- Developers reviewing structural changes
- Teams preparing migration or integration
- Technical reviewers comparing two system states
- Builders who need a readable report instead of raw JSON only

## What the customer provides
- First JSON structural state
- Second JSON structural state
- Optional short explanation of the comparison goal

## What the customer receives
- Compatibility verdict
- Compatibility score
- Structural findings
- Risk interpretation
- Practical recommendation
- Human-readable report based on SCA-Unit public outputs

## Service boundary
This service uses public SCA-Unit outputs only.

## Safety boundary
No AMNE internals or protected structural architecture exposed.

## Publishing principle
Public visibility only. No outreach. No cold messages.
