# SCA-Unit Customer Value Language Policy v1.0

## Purpose
Define positive, clear, and confidence-building customer language for SCA-Unit while preserving accurate service boundaries.

## Core principle
SCA-Unit customer-facing language should build confidence, highlight value, and reduce confusion without overstating capabilities.

## Language direction
The service should be presented as useful, practical, clear, and controlled.

Customer-facing language should not sound fearful, defensive, or overly restrictive.

## Positive value statements
SCA-Unit helps users understand structural compatibility between two JSON structural state files.

SCA-Unit turns structural comparison into a readable report.

SCA-Unit supports clearer technical decisions by showing whether two structural representations are compatible, partially compatible, or meaningfully different.

SCA-Unit is useful when a user needs a focused structural comparison rather than a vague manual review.

## Boundary language
Boundaries should be written as clarity statements, not fear statements.

Use: This service focuses on structural comparison only.

Avoid: This service does not do many risky things.

Use: Please send only the two JSON files needed for comparison.

Avoid: Do not send dangerous or sensitive material.

## Customer confidence rule
Every customer message should include at least one clear value statement before any limitation statement.

## Limitation rule
Limitations should be short, factual, and calm.

## Preferred limitation wording
This report is a structural comparison report. It is not intended to replace legal, financial, medical, cybersecurity, or compliance advice.

## Avoided wording
Avoid language that makes the service sound unsafe, experimental, frightening, or legally defensive.

## Trust-building elements
- Clear input requirements
- Clear comparison scope
- Clear report output
- Calm limitation wording
- No exaggerated claims
- No hidden technical promises
- No AMNE internals or protected structural architecture

## Public positioning
SCA-Unit may be positioned as a practical structural compatibility assessment tool that produces readable reports from two JSON structural state files.

## Internal reminder
Accuracy protects the product. Positive clarity sells the product.
