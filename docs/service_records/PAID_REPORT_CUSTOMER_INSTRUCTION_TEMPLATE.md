# SCA-Unit Paid Report Customer Instruction Template

## Purpose
Provide simple customer instructions for requesting a structural compatibility report.

## What to send
Please prepare and send the following:

1. First structured JSON file.
2. Second structured JSON file.
3. Selected report type: Basic, Standard, or Expert.
4. Optional short comparison goal.

## Comparison goal examples
- I want to compare two API schemas before migration.
- I want to check whether two configuration structures are compatible.
- I want a readable report explaining structural differences.

## File requirements
- Files should be valid JSON.
- Files should represent structured states, schemas, configurations, or comparable objects.
- Do not include secrets, passwords, private keys, or confidential credentials.

## What you receive
- Compatibility verdict
- Compatibility score
- Structural findings
- Risk interpretation
- Practical recommendation
- Human-readable report

## Service boundary
Reports are based on public SCA-Unit outputs only.

## Safety boundary
No AMNE internals or protected structural architecture exposed.
