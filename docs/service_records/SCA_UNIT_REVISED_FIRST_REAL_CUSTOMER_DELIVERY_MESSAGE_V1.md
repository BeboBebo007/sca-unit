## Purpose
Provide the revised positive-language delivery message for sending the completed manual SCA-Unit Structural Report to the first real customer.

Approved public-safe positive customer delivery message template.

## Customer delivery message

Hello,

Thank you for using the SCA-Unit Structural Report service.

Your structural comparison report is now complete.

SCA-Unit has compared the two JSON structural state files you provided and prepared a clear, readable report showing the structural relationship between them.

The report is intended to help you understand whether the two structural representations appear compatible, partially compatible, or meaningfully different in structure.

Please review the attached or included report. If any section is unclear, you may ask for a brief explanation of the reported structural comparison results.

This report is a structural comparison report. It is not intended to replace legal, financial, medical, cybersecurity, or compliance advice.

Thank you again for using SCA-Unit.

Kind regards,
SCA-Unit
