# SCA-Unit First Real Customer Follow-Up Message v1.0

## Purpose
Provide a safe follow-up message after delivering the completed manual SCA-Unit Structural Report to the first real customer.

## Message status
Approved public-safe customer follow-up message template.

## Customer follow-up message

Hello,

I hope the SCA-Unit Structural Report was received successfully.

I would appreciate brief feedback on the report, especially whether the structural comparison was understandable and whether any section was unclear.

Please do not send confidential information, passwords, API keys, tokens, credentials, private keys, or unrelated private documents in your feedback.

Useful feedback may include:

1. Was the report easy to understand?
2. Was the comparison result useful?
3. Was any wording unclear?
4. Was the delivery process clear?
5. Would you improve anything in the report format?

Important limitation: this service provides a structural comparison report only. It is not a legal, financial, medical, cybersecurity, or compliance certification service.

Kind regards,
SCA-Unit

## Internal use note
Use this message only after delivering the approved customer-facing report.

## Evidence use
General feedback from this message may be recorded in the Evidence Register without customer secrets or private submitted data.

## Protected knowledge rule
This message must not mention AMNE internals or protected structural architecture.
