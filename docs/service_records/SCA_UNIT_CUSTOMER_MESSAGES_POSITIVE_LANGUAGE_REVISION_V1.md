# SCA-Unit Customer Messages Positive Language Revision v1.0

## Purpose
Define the positive language revision for SCA-Unit customer-facing messages created for the first real customer workflow.

## Revision principle
Customer messages should begin with value, clarity, and usefulness before stating calm service boundaries.

## Updated intake message direction
Lead with: SCA-Unit helps turn two JSON structural state files into a readable structural comparison report.

Then explain what the customer should send.

State limitations calmly as service focus, not fear.

## Updated correction message direction
Lead with: The request appears close to the correct workflow, but a small correction is needed before generating the report.

Then list the correction items clearly.

Avoid making the customer feel rejected when the request is fixable.

## Updated rejection message direction
Lead with appreciation and clarity.

Explain that the current request does not match the focused structural comparison workflow.

Invite a corrected future request when appropriate.

## Updated delivery message direction
Lead with completion and value.

State that the report presents the structural comparison in readable form.

Invite clarification questions without implying extra certification or hidden services.

## Updated follow-up message direction
Lead with customer experience and improvement.

Ask whether the report was useful, clear, and easy to follow.

Use feedback as evidence for product improvement.

## Preferred customer wording
- This report helps clarify structural compatibility between two JSON state files.
- The service focuses on structural comparison.
- Please send the two JSON files needed for comparison.
- The report is intended to support clearer technical understanding.
- Feedback helps improve the report format and service experience.

## Wording to avoid
- Dangerous files
- Risky material
- Unsafe request unless truly necessary
- Many things this service cannot do
- Defensive legal language
- Fear-based disclaimers

## Calm limitation wording
This report is a structural comparison report. It is not intended to replace legal, financial, medical, cybersecurity, or compliance advice.

## Public value sentence
SCA-Unit turns structural comparison into a clear, readable report from two JSON structural state files.

## Protected knowledge rule
No revised customer message may mention AMNE internals or protected structural architecture.
