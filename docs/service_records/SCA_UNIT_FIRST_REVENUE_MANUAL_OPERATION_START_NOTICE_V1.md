# SCA-Unit First Revenue Manual Operation Start Notice v1.0

## Purpose
Provide a controlled start notice for the first manual revenue operation of the SCA-Unit Structural Report service.

## Notice status
First revenue manual operation start notice.

## Notice source
This notice follows the completed first revenue manual operation Go gate.

## Revenue operation status
Ready to start only after a suitable request passes the Go gate.

## Start condition
The first manual revenue operation may start only when:
- The request passes the acceptance checklist
- The Go gate decision is Go
- The selected tier is agreed
- The payment path is agreed
- The work boundary is understood

## Preferred first revenue offer
Standard Report at 29 EUR.

## Customer request boundary
The request must include exactly two JSON structural state files, clear file order, and a short explanation of the structural change.

## Do not start if
- A file is missing
- File order is unclear
- JSON structure is invalid or incomplete
- Credentials or secrets are included
- Sensitive personal data is included
- The request is outside structural comparison
- The customer expects legal, financial, medical, cybersecurity, compliance, or full audit advice

## Work allowed after start
- Validate input files
- Generate raw SCA-Unit assessment
- Generate manual Structural Report
- Review report
- Deliver report
- Record payment and closure status

## Revenue boundary
This notice covers the first manual revenue operation only. It does not include automated checkout, subscriptions, enterprise billing, or tax handling.

## Protected knowledge rule
This start notice must not expose AMNE internals or protected structural architecture.

## Final notice result
Ready to start the first manual revenue operation only after a suitable request passes the Go gate.
