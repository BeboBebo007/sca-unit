## Customer intake message

Hello,

Thank you for your interest in the SCA-Unit Structural Report service.

SCA-Unit helps turn two JSON structural state files into a clear, readable structural comparison report.

The report is designed to help you understand whether two structural representations are compatible, partially compatible, or meaningfully different in structure.

To prepare the report, please send:

1. The first JSON structural state file
2. The second JSON structural state file
3. A short note confirming which file represents the first state and which file represents the second state

The service focuses on structural comparison. Please send only the two JSON files needed for the comparison.

For clarity and good handling, please avoid including passwords, API keys, tokens, private keys, credentials, confidential secrets, unrelated private documents, or sensitive personal data in the files.

This report is a structural comparison report. It is not intended to replace legal, financial, medical, cybersecurity, or compliance advice.

After receiving the files, I will review whether they match the service scope and then proceed with the manual report workflow.

Kind regards,
SCA-Unit
