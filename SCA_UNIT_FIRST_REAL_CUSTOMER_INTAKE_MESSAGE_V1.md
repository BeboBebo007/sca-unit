## Customer intake message

Hello,

Thank you for your interest in the SCA-Unit Structural Report service.

This is a manual structural comparison service. It compares two JSON structural state files and produces a readable structural report.

To proceed safely, please send only the following:

1. The first JSON structural state file
2. The second JSON structural state file
3. A short note confirming which file is the first state and which file is the second state

Please do not include passwords, API keys, tokens, private keys, credentials, confidential secrets, unrelated private documents, or sensitive personal data in the files.

Important limitation: this service is not a legal, financial, medical, cybersecurity, or compliance certification service. It provides a structural comparison report only.

After receiving the files, I will check whether the request is safe and within scope. If something needs correction, I will ask you to resend corrected files before any report is generated.

Kind regards,
SCA-Unit
