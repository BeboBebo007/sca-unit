# SCA-Unit First Real Customer Public Service Readiness Notice v1.0

## Purpose
Provide a public-safe readiness notice stating that the manual SCA-Unit Structural Report service is ready for a controlled first real customer request.

## Notice status
Public-safe service readiness notice.

## Public notice

SCA-Unit Structural Report service is ready for a controlled first customer request.

SCA-Unit turns structural comparison between two JSON structural state files into a clear, readable report.

The service is currently operated manually and is intended for focused structural comparison requests only.

A suitable first request should include exactly two JSON structural state files and a short note confirming which file represents the first state and which file represents the second state.

The generated report may help clarify whether the two structural representations appear compatible, partially compatible, or meaningfully different in structure.

This service focuses on structural comparison. It is not intended to replace legal, financial, medical, cybersecurity, or compliance advice.

## Accepted request type
- Two JSON structural state files
- Clear first-state and second-state order
- Structural comparison only

## Not accepted
- Passwords, API keys, tokens, private keys, credentials, or confidential secrets
- Unrelated private documents
- Sensitive personal data
- Requests outside structural comparison

## Service mode
Manual controlled service operation.

## Customer language rule
Lead with value, clarity, and usefulness before stating calm service boundaries.

## Protected knowledge rule
This notice must not mention AMNE internals or protected structural architecture.
