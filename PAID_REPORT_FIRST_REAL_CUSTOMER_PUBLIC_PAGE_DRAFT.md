# SCA-Unit Paid Structural Report Service

## What this service provides
SCA-Unit Paid Structural Report is a manual structural compatibility assessment based on two JSON structural state files provided by the customer.

## What the customer provides
- First JSON structural state file
- Second JSON structural state file
- Confirmation of which file is the first state and which file is the second state

## What the customer receives
- A paid Markdown structural report
- Raw SCA-Unit assessment JSON only if included in the agreed service scope

## Important safety notice
Customers must not submit passwords, access tokens, API keys, private keys, credentials, secrets, or unrelated private implementation details.

## Service limitations
This service is not legal, financial, medical, cybersecurity, or compliance certification.

## Manual service boundary
This is a manual service. It does not include automated payment handling, automated ordering, a customer portal, or continuous monitoring.

## Protected architecture boundary
This service uses the public SCA-Unit workflow only. It does not expose AMNE internals or protected structural architecture.
