# SCA-Unit Public Product Presentation

## What is SCA-Unit?
SCA-Unit is a public Python tool for structural compatibility assessment between two structured software or logical states.

## What problem does it solve?
Many software changes look small at the surface, but introduce structural differences that can affect migration, integration, review, or system evolution.

## Public package
- PyPI package: sca-unit
- Current public version: 0.4.0
- CLI command: sca-unit

## Paid layer
SCA-Unit can be used as the foundation for paid structural compatibility reports.

## First paid workflow
Customer inputs two JSON structural states. The service runs SCA-Unit, generates a raw JSON assessment, and converts it into a human-readable structural report.

## What is not included
This public presentation does not expose AMNE internals or protected structural architecture.
