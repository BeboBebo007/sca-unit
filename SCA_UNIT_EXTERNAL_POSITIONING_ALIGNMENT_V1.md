# SCA-Unit External Positioning Alignment v1.0

## Purpose
Define the public external positioning of SCA-Unit as a Structural Assessment Engine with a JSON-first implementation.

## Positioning status
External positioning alignment.

## Core statement
SCA-Unit is a Structural Assessment Engine for comparing two structured states and producing a deterministic structural compatibility assessment.

## Current implementation scope
The current public implementation is JSON-first. It accepts two JSON structural state files and produces a structured assessment report.

## What SCA-Unit is
SCA-Unit is:
- a structural compatibility assessment tool
- a deterministic comparison engine for structured states
- a public assessment layer for review, migration, integration, and system-evolution workflows
- a foundation for manual Structural Report generation

## What SCA-Unit is not
SCA-Unit is not:
- a generic text diff tool
- a line-by-line file comparison tool
- a legal, financial, medical, cybersecurity, or compliance advisor
- an automated enterprise audit platform

## Why JSON first
JSON is used as the first public input format because it is simple, portable, deterministic, and easy to inspect.

## Future extension direction
Future public versions may extend the same structural assessment approach to additional structured formats such as YAML, OpenAPI, graphs, and data schemas.

## Evidence direction
SCA-Unit reports should make structural evidence understandable through scores, compatibility signals, conflict indicators, and a readable verdict.

## Public language rule
Public documentation should describe the documented SCA-Unit workflow without naming protected internal systems or unpublished architecture.

## Final positioning result
SCA-Unit should be understood externally as a JSON-first Structural Assessment Engine, not merely as a JSON comparison utility.
