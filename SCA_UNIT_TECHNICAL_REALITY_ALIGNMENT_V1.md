# SCA-Unit Technical Reality Alignment v1.0

## Purpose
Align the technical description of SCA-Unit with the current public implementation.

## Alignment status
Technical reality alignment.

## Current technical reality
The current public SCA-Unit implementation is a small deterministic structural comparison core.

## Current implemented capabilities
- Compare two JSON structural states
- Compare node sets
- Compare edge sets
- Produce node similarity
- Produce edge similarity
- Produce structural compatibility
- Detect simple shared-domain conflict
- Produce a structural verdict

## Current limitation
The current implementation is still close to set-based comparison and does not yet provide a multi-dimensional structural assessment engine in the stronger technical sense.

## Important clarification
The current public package should not be described as an enterprise reasoning platform, self-evolving system, optimization layer, or protected decision mechanism.

## Correct current positioning
SCA-Unit is currently a foundational deterministic structural comparison core for JSON-first structural states.

## Why this is still useful
A small deterministic core is useful if it is clear, tested, reproducible, and positioned honestly as the first layer of a larger structural assessment roadmap.

## Gap to close next
The next technical step must introduce a capability that cannot be reduced to raw Jaccard similarity.

## Selected next capability
Typed Relation Conflict Engine.

## Product direction
SCA-Unit remains the core. SCA-Audit Lite may later become the paid report service for auditing one software or AI project at a time.

## Not started now
- No company-wide audit platform
- No SaaS build
- No automated payment
- No enterprise integration
- No unsupported format claims

## Final alignment result
The project now has a clear technical reality statement before adding the first deeper structural capability.
